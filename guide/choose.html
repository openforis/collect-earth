Which set-up?

Collect Earth always saves each plot on the interpreter's own computer first. The four ways of working differ in how those plots are brought together, and how much a coordinator can see while the work goes on.

How to choose

  • Working alone? Set-up 1. You can move to a cloud project later.
  • A team, and the internet works at least once a day? Set-up 3. Nothing to install beyond Collect Earth, and the coordinator gets progress, quality checks, training and the time spent per plot.
  • A team that must keep its data on its own servers? Set-up 4. It works exactly like set-up 3, on a server you install and pay for.
  • A team with no internet at all? Set-up 2, with regular exports from each computer. More manual work, fewer checks.

Set-ups 3 and 4 still work offline: each interpreter keeps working, and the plots are sent when the connection comes back.

1. One interpreter, on one computer

Install Collect Earth, open the project file and assess the plots. Everything stays in the SQLite database on that computer; only the imagery needs the internet. Tools › My dashboard shows your progress. See Collect Earth for interpreters.

2. A team, without a server

Each computer its own database. Give everyone the same project file and their own plot file (Utilities › Divide large CSV plot files splits one). Each interpreter exports regularly with Export data › XML (compressed), choosing Records modified since the last export, and sends the file to the coordinator, who brings them together with Import data.

Locally, a database keeps one version of each plot. To compare two people's answers on the same plot, keep the second export apart, or use a cloud project, which keeps both.

One shared PostgreSQL database. On an office network, IT sets up PostgreSQL and every computer chooses Settings › Data storage › PostgreSQL. Everyone's saves go into one database, with no exports to carry. Never give the same plot to two people: the last save wins.

3. Collect Earth Cloud

The free server run by the Collect Earth team, at cloud.collectearth.org. The coordinator creates a project and invites the team with a link; interpreters join from Collect Earth, and their plots reach the dashboard by themselves. Two people's answers on the same plot are both kept and compared. See Running a cloud project.

4. Your own server

Your own copy of Collect Earth Cloud. Coordinators and interpreters work exactly as in set-up 3; only the address differs, and nobody else can see the data. See Your own server.

Moving from local work to a cloud project

Upload the same project file to the server. Plots already assessed can come along: each interpreter joins the project and uses Data Import/Export › Send this computer's records to the cloud project, or the coordinator imports a compressed XML export on the dashboard's Data tab.
