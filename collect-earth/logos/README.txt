COLLECT EARTH · LOGO 2026
=========================

Three formats, same structure inside each:

  SVG/  vector, for web and digital
  EPS/  vector, for print and design software
  PNG/  transparent background, ready-made sizes (width in the file name)
  VIDEO/ logo reveal animation, 1920x1080, 60 fps, 12 s, no audio

Folders
  01_Horizontal_OpenForis   main logo, with "Open Foris"
  02_Horizontal             without "Open Foris"
  03_Vertical_OpenForis     stacked, with "Open Foris"
  04_Vertical               stacked, without "Open Foris"
  05_Emblem                 the emblem alone
  06_Emblem-Small           simplified emblem for 32-64 px
  07_Favicon                the nine points, for browser tabs and bookmarks (+ favicon.ico)
  08_Installer-Icon         icon for the setup file (+ .ico)

Versions
  Dark        dark text, for light backgrounds
  White       white text, for dark backgrounds
  Mono-Black  one colour, black (#1E2226)
  Mono-White  one colour, white

Which one to use
  From 180 px / 45 mm wide     Horizontal with Open Foris
  120-180 px / 30-45 mm        Horizontal without Open Foris
  Below 120 px / 30 mm         Emblem
  32-64 px                     Emblem-Small
  16-32 px                     Favicon (nine points)

Clear space: x = one third of the emblem's width, on every side.
